## Интернет-магазин
### Описание

* В данном проекте было реализовано приложение "catalog", в котором есть два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
* HTML-шаблоны используют стилизацию Bootstrap.
* Созданы контроллеры для отображения домашней страницы и страницы с контактной информацией.
* Настроена маршрутизация для этих контроллеров.
* Реализована форма обратной связи на странице контактов.
* Реализованы настройки в файле подключения к базе данных. 
* В приложении "catalog" созданы модели "Category" и "Product",а так же описаны для них базовые настройки.
* Созданы миграции для новых моделей.
* Создан суперпользователь админки,так же настроено отображение для моделей,настроена фильтрация и поиск.
* Установлены зависимости для работы с Django shell
* Сформированы фикстуры для моделей "Category" и "Product"
* Создана кастомная команда для добавления тестовых продуктов. В команде реализована функциональность удаления данных из базы перед добавлением новых продуктов.
