## Интернет-магазин
### Описание

* В данном проекте было реализовано приложение "catalog", в котором есть два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
* HTML-шаблоны используют стилизацию Bootstrap.
* Созданы контроллеры для отображения домашней страницы и страницы с контактной информацией.
* Настроена маршрутизация для этих контроллеров.
* Реализована форма обратной связи на странице контактов.
